Run /usage in Claude Code and copy the two figures across. Reset times are whatever it prints, in your own timezone. Nothing leaves this browser.

Weekly limit

A rough count is enough. Without it the budget stays in percentages; with it, every figure also shows in hours.

5-hour session

Arithmetic on figures you type in. No account, no API key, no network calls, no analytics. Readings are kept in this browser's local storage and nowhere else. Each day's share is the quota you have left divided by the hours until reset, so a part-spent today and a mid-morning reset day get proportionally smaller shares than a whole day.
